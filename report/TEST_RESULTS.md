## Не перевірено / поза межами

- Доступ із телефона або іншого фізичного пристрою. Shared Network не має підтвердженого маршруту з телефона; Bridged не вмикався.
- Повне перезавантаження Ubuntu/VM. Автозапуск налаштований, але reboot не проводився.
- Фізичний друк, USB-передавання, драйвер і черга принтера; інтеграція Express–CUPS відсутня.
- Навантаження, гранична кількість користувачів, усі формати PDF й антивірусна перевірка.
- Штучний збій deploy/rollback, вимкнення живлення під час запису, відновлення резервної копії.
- Production-вхід адміністратора зі справжнім паролем, очищення реальної історії. Перевірки цих API проведені на тимчасових даних.
- Повна кросбраузерність, доступність та всі мобільні розміри.

## Зауваження

- Vite попереджає про JS-пакет понад 500 кБ. Це не блокувало збірку; оптимізація не потрібна для поточного показу.
- Початкове розгортання відбулося до корекції годинника VM, тому його каталог release та частина початкових записів можуть мати дату 11.11.2026. Дата підготовки звіту — 13.11.2026. Після корекції chrony підтвердив поточний UTC.
- PDF зберігаються незалежно від очищення журналу; автоматичне видалення PDF і квоти не реалізовано.
- API працює через HTTP у приватній підмережі Parallels. Публічне розміщення й перенаправлення портів роутера не налаштовувалися.

## Документи

- Справжній DOCX (OOXML ZIP) і PDF експортовано через LibreOffice 26.8.3.
- PDF: **31 сторінка загалом; 28 до додатків; додатки починаються на сторінці 29**.
- Усі заголовки звірено з очікуваними сторінками; зміст відповідає фактичній пагінації. Порожніх сторінок немає.
- DOCX: A4, Times New Roman 14 пт, основний інтервал 1,5, відступ 1,25 см, поля 3/1,5/2/2 см. Для змісту, підписів і технічних фрагментів використано компактне оформлення.
- pdffonts підтвердив вбудовані TimesNewRomanPSMT і TimesNewRomanPS-BoldMT у фінальному PDF.
- 7 рисунків: архітектурна схема + 6 справжніх скриншотів. Усі мають номер, підпис і згадку в тексті.
- Нумерація сторінок — поле PAGE, титульна сторінка без видимого номера.
- Переглянуто відрендерені титул, зміст, теоретичну сторінку, схему, початок практичного розділу, сторінку systemd і сайт.
- Деталі автоматичної перевірки: document-validation.json.
- Невідомі реквізити титулу не вигадано. Методичні вимоги кафедри не надано; параметри для узгодження вказано в додатку А.
